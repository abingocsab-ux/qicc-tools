How the skill matrix works

1 · Grading scale (0–4)

Every competency is graded on the standard 5-level scale:

  • 4 – Expert (trainer level): trains others, solves complex issues independently
  • 3 – Perform effectively: works independently with consistent quality
  • 2 – Perform: runs the task but may need guidance for setup / troubleshooting
  • 1 – Perform with help: needs supervision, step-by-step support
  • 0 – Cannot perform: not familiar with the task

2 · Machine score & position

Each machine gets two grades — Setup and Operating — which add up to a machine score out of 8. The score decides the position on that machine:

Machine score = Setup + Operating (max 8)
0 → Untrained  ·  1–3 → Trainee  ·  4 → Assistant  ·  5–7 → Operator  ·  8 → Sr. Operator

Untrained (score 0) means the operator cannot yet perform setup or operating on that machine. It is different from a blank cell, which means the machine has never been assessed for that operator — blanks still count as 0 toward the polyvalence %, but only an explicit 0 is reported as Untrained.

3 · Overall performance %

Every grade for the section is added together — Setup + Operating for each machine, plus any marking-unit skills (Extrusion only). Blank cells count as 0, same as the Excel workbook. The maximum adjusts to each section's machine count (Extrusion 76, Assembly 104, Metallurgy 64):

Performance % = (sum of all grades ÷ section maximum) × 100

As a guide: ≥70% strong, 45–69% developing, <45% needs a training plan.

4 · Supervisor Assessment

Separately from machine polyvalence, supervisors log a quick assessment per visit — Safety, Quality, Standard and Improvement. Every item is a simple + / − counter, so the supervisor just taps how many times they observed it. The score is a point total, not a percentage, and is calculated automatically:

Score = sum of all observed points · starts at 0 · no cap on any item · may be negative
Safety SUSA Reporting +3 each · Safety Violation −5 each
Quality Human Error NC −5 each · NC Reporting +2 each · Production without NC +1 each
Standard Followed Standard +5 each · Not Following Standard −10 each
Improvement Idea Sharing +10 each
Outstanding ≥ +30 · Excellent +20 to +29 · Very Good +10 to +19 · Good +1 to +9 · Needs Improvement 0 to −10 · Unsatisfactory < −10

A blank form scores 0 — every point is earned by what the supervisor actually observes. Nothing is capped, so repeated good practice keeps adding up and repeated violations keep subtracting. When violations outweigh the positives the total goes negative, which reads as Needs Improvement and then Unsatisfactory.

Each operator's Supervisor Assessment history and rolling averages appear in their Person Summary; team-wide trends appear on the Supervisor Assessment dashboard, and the Group Summary tab shows polyvalence and assessment points side by side for the whole team.

5 · Gaps, roadmap & deviations

A machine started but below score 5 is flagged as a skill gap and can be converted into a training action in one click. Deviations are logged in the Deviations tab and shown in each person's summary, so grades, roadmap progress and quality events are read side by side.

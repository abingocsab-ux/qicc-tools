HOW THIS CALCULATOR WORKS ✕ close

The core formula

Total setup time (per machine, per size) = Initial setup time + Changeover time
Changeover time = Number of drum × Changeover rate per drum
Number of drum = ⌈ Batch length ÷ Length of drum ⌉ — rounded up, since a fraction of a drum change still counts as one.

Which processes scale with core count

Only Bunching, Stranding, and Insulation multiply batch length by core count before dividing by drum capacity (capped at ×1 once core ≥ 6). Every other process — Bedding/Filling, Armouring, Sheathing, Hypron — scales with batch length alone, using a fixed drum capacity.

Taping — two separate changeovers

Taping isn't one number: it's payoff/take‑up drum changeover (sharing the same drum & capacity as Armouring/Sheathing/Hypron) plus tape coil changeover (its own length/coil). Total = both subtotals added together. Switching Armouring to "Wire" zeroes Taping entirely, since wire‑armoured cable skips that stage; switching to "Tape" zeroes the wire‑armouring machines instead.

Scrap uses the exact same drum counts

Scrap = scrap‑per‑drum‑change × number of drum changes — the same Drawing/Insulation/Hypron drum counts that drive setup time, not a separate calculation. Testing is the one flat per‑batch exception. Edit a drum capacity once in the Number of Drum panel and both setup time and scrap update together.

Routing mask & other toggles

  • Core count sets which sizes are even valid (1 core: 1.5–800 mm², 2–5 core: 1.5–300 mm², 6+ core: 1.5–6 mm²) and zeroes Assembly machines at 1 core.
  • Armouring (Wire/Tape) toggles between the wire‑armouring machines and the taping stage.
  • Extrusion line (LV/MV) picks between the standard insulation line and the CV line — only one runs at a time, and MV further restricts sizes to 16–800 mm².
  • Scrap type (Hypron/Non‑Hypron) swaps which scrap rate set is active, independently editable.
  • A cell shows — whenever the routing reference says that machine doesn't run that size, regardless of the math above.

Everything is editable, nothing is hidden

Every rate, capacity, and drum count shown anywhere in this app traces back to a real default from the source workbooks, but every one of them can be overridden per size in ⚙ Setup time parameters. Use 💾 Save / 📂 Load to keep a config file, or ⬇ Download updated app to bake your edits into a new copy of the whole tool.
